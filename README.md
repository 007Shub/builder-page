#  Shubh Limbani — Builder Page

My personal builder page. Project #1 of many (source: trust me bro).

## What is this?

A plain HTML/CSS page that introduces me:

- **Who:** Shubh Limbani ([@007Shub](https://github.com/007Shub)), from India 🇮🇳
- **What I build:** my skills, one tutorial at a time — this page is my first shipped project

## Run locally
